## **1️⃣ Instalace GitHub Desktop**

GitHub Desktop umožňuje snadnou práci s Git repozitáři bez příkazové řádky.

### **Jak nainstalovat GitHub Desktop?**

1. **Stáhni GitHub Desktop**
    
    - Přejdi na 👉 [https://desktop.github.com/](https://desktop.github.com/)
        
    - Klikni na tlačítko **Download for Windows** (nebo Mac, podle OS).
        
2. **Nainstaluj GitHub Desktop**
    
    - Otevři stažený soubor a nainstaluj aplikaci podle pokynů.
        
3. **Přihlas se do GitHubu**
    
    - Po spuštění aplikace klikni na **Sign in to GitHub.com**
        
    - Přihlas se nebo si vytvoř nový účet na **[GitHub.com](https://github.com/)**
        
4. **Naklonuj repozitář se zápisky**
    
    - Klikni na **Clone a repository from the Internet**
        
    - Najdi repozitář se školními zápisky
        
    - Klikni na **Clone** a vyber složku, kam se repozitář stáhne.
        
5. **Hotovo! 🎉**  
    Teď máš repozitář na svém počítači a můžeš pracovat.

## **2️⃣ Instalace Obsidian**

Obsidian je nástroj pro psaní a organizaci poznámek ve formátu **Markdown (.md)**.

### **Jak nainstalovat Obsidian?**

1. **Stáhni Obsidian**
    
    - Přejdi na 👉 [https://obsidian.md/](https://obsidian.md/)
        
    - Klikni na **Download** a vyber verzi pro svůj operační systém.
        
2. **Nainstaluj a spusť Obsidian**
    
    - Otevři stažený soubor a postupuj podle instrukcí instalace.
        
    - Po instalaci aplikaci spusť.
        
3. **Otevři složku se zápisky**
    
    - Klikni na **Open folder as vault**
        
    - Vyber složku, do které jsi naklonoval repozitář v GitHub Desktopu.
        
4. **Hotovo! 🎉**  
    Teď můžeš psát a upravovat zápisky v Obsidianu.
